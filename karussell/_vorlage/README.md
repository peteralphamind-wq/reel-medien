# Karussell-Vorlage (dunkles Design)

`render.js` baut die Folien als 1080 × 1350 JPG mit Playwright. Folientexte stehen oben im Array `slides`, das Thema oben rechts in `TAG`.

    node karussell/_vorlage/render.js karussell/<jahr-monat>-<thema>

Logo und Porträt sind aus früheren Folien ausgeschnitten.
